# 旅行助手（簡易版）

## 在 Windows 電腦開啟
1. 在此資料夾的網址列輸入 `cmd` 開啟終端機。
2. 執行 `python -m http.server 8000`。
3. 瀏覽器開啟 `http://localhost:8000`。

## 自動儲存
- 新增或編輯資料時，輸入後短暫停頓會自動儲存，不必每次按「完成」。
- 表單下方會顯示「正在儲存…」或「✓ 已自動儲存」。
- 資料儲存在目前瀏覽器。清除網站資料或更換裝置／瀏覽器可能導致資料無法讀取。
- 建議定期使用「匯出資料」備份。電腦與 iPhone 的資料不會自動同步。

## 功能
- 行程時間軸與目前／下一站選擇
- Google Maps 快速導航
- 店家價格、營業時間、地址、個人備註及圖片
- JSON 匯入／匯出備份
