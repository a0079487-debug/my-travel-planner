# 旅行行程（簡化版）

## 使用方式
1. 解壓縮 ZIP。
2. 在資料夾開啟終端機。
3. 執行 `python -m http.server 8000`。
4. 瀏覽器開啟 `http://localhost:8000`。

## 功能
- 行程時間線：依時間排序，可手動指定首頁顯示的現在／下一站。
- 首頁不顯示預定時間，按一下即可開啟 Google 地圖。
- 店家紀錄：名稱、價格、營業時間、地址、備註、圖片；每家店可直接開啟 Google 地圖。
- 行程與店家紀錄可新增、編輯、刪除。
- 淺藍色與白色的簡潔介面，移除消費記帳、待辦與預算區塊。
- 可匯出 JSON 備份並匯入還原。
- 資料儲存在目前瀏覽器，不會自動同步其他裝置；請定期匯出備份。
